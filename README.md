# Markiplier's Domain

Build a polished 3-page responsive fan website for Markiplier, the gaming YouTuber and streamer.

This is a fan-made project for a college club recruitment challenge, so prioritize exceptional frontend design, visual polish, responsiveness, and smooth interactions over complex functionality.

DESIGN:

- Dark cinematic gaming aesthetic

- Near-black background

- White/off-white typography

- Deep red accent color

- Premium, modern, slightly dramatic atmosphere

- Large bold typography

- High-quality creator imagery

- Subtle gradients, glow effects, grain/noise texture

- Smooth hover and scroll animations

- Avoid generic SaaS/dashboard styling

- Make it feel like a professionally designed creator website

PAGE 1 — HOME:

- Sticky navbar with MARKIPLIER logo/name

- Navigation: Home, Archive, Community

- Large cinematic hero section

- Markiplier image prominently displayed

- Short tagline: "ENTER AT YOUR OWN RISK."

- CTA buttons: "WATCH LATEST" and "EXPLORE ARCHIVE"

- Featured/latest video section

- Short "About Markiplier" section

- Creator/social links

- Footer

PAGE 2 — ARCHIVE:

- Title: "THE ARCHIVE"

- Grid of video cards

- 6–8 fictional/sample video entries using real Markiplier video titles where appropriate

- Categories: Horror, Comedy, Challenges, Series

- Category filtering

- Video thumbnails

- Hover effects with play button

- Clicking a video should open its YouTube URL in a new tab

PAGE 3 — COMMUNITY:

- Title: "JOIN THE DISTRACTION"

- Short fan/community introduction

- Fan submission form with:

  Name

  Email

  Favorite Markiplier video

  Message

- Submit button

- Form validation

- Success state after submission

- Design the form so it can later be connected to a backend

- Include social/community links

TECHNICAL:

- React

- Tailwind CSS

- Responsive desktop/tablet/mobile design

- Component-based architecture

- Clean reusable components

- No unnecessary dependencies

- Use placeholder images where necessary rather than broken images

- Make all navigation functional

- Add subtle but polished animations

- Ensure accessibility and good contrast
